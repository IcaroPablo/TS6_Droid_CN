# TS6 Droid 简中版 v2.1.7-Han

这次更新把**桌面端语义的密聊（Whisper）**真正做了回来，并补齐了几处长期缺失的交互。

## 密聊 / 密语

- **按住密聊才发**：底栏主麦克风左侧新增琥珀色「密聊麦克风」（带密语角标），悬浮窗面板内也有一个。
  按住时麦克风只把声音发给密语列表里的目标，松手立刻恢复频道发言；按住前的麦克风模式
  （按住说话 / 语音激活 / 开放麦）原样还原。不需要先切换任何模式。
- **句子开头不会漏音**：按下时先切路由、等原生目标集就位后才开麦；松开时先关麦再清路由。
- **服务器组密语是真正的服务器端路由**：按 TS3 协议 1.8.2.1 发送组密语包（`VoiceWhisper` +
  `Newprotocol` + `GroupWhisperType::ServerGroup`）。一个组只算一个目标，组内成员**后加入也能立刻听到**；
  不需要把组展开成客户端列表，也就不受「密语客户端数」上限拖累。
- **密语列表编辑器**（顶栏密聊图标）：服务器组 / 频道 / 成员三段勾选，组名来自服务器的
  `servergrouplist`，组行显示在线人数；成员行右侧按钮、长按成员面板、长按频道行都能直接加入 / 移出。
- 目标按 **UID 归档**，断线自动重连后列表自动重新下发；目标全部离线时丢弃语音而不是回落成频道广播；
  输入的文字以私信发给同一批人；有人密语你时成员头像与悬浮窗气泡转为琥珀色，并提示一次（15 秒去抖）。

## 成员信息与频道

- **长按任意成员（包括自己）**：面板显示其**服务器组**与**频道组**，组名来自服务器的
  `servergrouplist` / `channelgrouplist`；服务器未提供组名时回退 `#id`，组多时该栏独立滚动。
- **带密码的频道**：频道行显示锁图标，点击弹出密码框（悬浮窗内为内联输入），确认后带密码进入频道，
  不再「点了没反应」；密码不保存，输入错误仍由服务端错误提示反馈。
- **频道内改临时昵称**：长按自己 →「修改临时昵称」，走 `clientupdate client_nickname` 立即生效；
  只对本次连接有效，不写身份文件，重连后恢复连接时使用的昵称。

## 底层

- 原生库基于 `tslib_multi` 8e0bc11 **加补丁后自行交叉编译**，补丁随仓库提交
  （`patches/tslib_multi-8e0bc11-whisper-groups.patch`，已验证可干净应用到 8e0bc11）。
- 修复两处 JNI 签名漂移：`nativeMoveToChannel` 增加频道密码参数、`OpusCodec.nativeDecode` 增加 FEC 参数。
- 接收语音改为**推送式回调**（这也是唯一能区分「密语包」与「频道包」的地方），
  事件式 `audio_received` 播放路径随之移除，避免双播。
- 单元测试 **46 → 75**；`tslib` 侧另有 60 项 Rust 单元测试（含按协议文档钉住的组密语包字节布局）。

## 安装与升级

- 本包为**正式签名**，可直接覆盖安装；要求 **Android 8.0+（API 29）** 且为 **arm64** 设备。
- 从 v2.1.6 升级无需任何数据迁移；密语列表与私聊归档沿用同一套 UID 会话键。
- 校验值见同名 `.sha256` 文件；完整源码见本 tag（GPLv3）。
