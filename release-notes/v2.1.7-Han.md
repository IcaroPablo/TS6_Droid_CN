## 更新日志 (Changelog)

> 密聊在 v2.1.5 被移除后，这一版以**桌面端语义**重新实现；原生库同步升级到带密语接口的构建（补丁随仓库提交，可复现）。

### 💬 密聊 / 密语（Whisper）
- **按住密聊才发**：底栏主麦克风左侧新增**琥珀色密聊麦克风**（带密语角标），悬浮窗面板内也有一个。按住时麦克风只把声音发给密语列表里的目标，松手立刻恢复频道发言——不需要先切换任何模式
- **句子开头不漏音**：按下先切路由、等原生目标集就位后才开麦；松开先关麦、再清路由。按住前的麦克风模式（按住说话 / 语音激活 / 开放麦）原样还原
- **服务器组密语走协议原生路由**：按 TS3 协议 1.8.2.1 发送组密语包（`VoiceWhisper` + `Newprotocol` + `GroupWhisperType::ServerGroup`），由服务器解析组成员。**一个组只算一个目标**，组内成员后加入也能立刻听到，不必展开成客户端列表
- **密语列表编辑器**（顶栏密聊图标）：服务器组 / 频道 / 成员三段勾选，组名来自服务器的 `servergrouplist`，组行显示在线人数；成员行右侧按钮、长按成员面板、长按频道行都能直接加入 / 移出
- 目标按 **UID 归档**，断线自动重连后列表自动重新下发；目标全部离线时丢弃语音而不是回落成频道广播；输入的文字以私信发给同一批人
- 有人密语你时，成员头像与悬浮窗气泡转**琥珀色**，并提示一次（15 秒去抖）

### 👥 成员信息
- **长按任意成员（包括自己）**：面板显示其**服务器组**与**频道组**，组名来自服务器的 `servergrouplist` / `channelgrouplist`；未取到组名时回退 `#id`，组多时该栏独立滚动
- 自己那一行只显示身份与组信息，音量 / 静音 / 私信 / 密聊这些「对自己无意义」的操作会隐藏

### 🚪 频道
- **带密码的频道**：频道行显示锁图标，点击弹出密码框（悬浮窗内为内联输入，因为悬浮窗是 `WRAP_CONTENT`，全屏对话框会被裁切），确认后带密码进入，不再「点了没反应」；密码不保存
- **频道内改临时昵称**：长按自己 →「修改临时昵称」，走 `clientupdate client_nickname` 立即生效；只对本次连接有效，不写身份文件，重连后恢复连接时使用的昵称

### 🔧 底层
- 原生库基于 `tslib_multi` 8e0bc11 **加补丁后自行交叉编译**，补丁随仓库提交（`patches/tslib_multi-8e0bc11-whisper-groups.patch`），可干净应用到该提交
- 修复两处 JNI 签名漂移：`nativeMoveToChannel` 增加频道密码参数、`OpusCodec.nativeDecode` 增加 FEC 参数
- 接收语音改为**推送式回调**（这也是唯一能区分「密语包」与「频道包」的地方），事件式 `audio_received` 播放路径移除，避免双播
- 单元测试 **46 → 75**；`tslib` 侧另有 60 项 Rust 单元测试（含按协议文档钉住的组密语包字节布局）

### 🐛 Bug 修复
- 修复密语列表非空时按住密聊麦克风仍提示「列表为空」：手势回调持有的是第一次组合时的旧状态
- 修复带密码频道点击无反应（此前没有任何密码入口，服务端拒绝后界面无提示）
- 修复悬浮窗频道列表对带密码频道静默失败（改为内联密码输入）

### ⚠️ 注意
- 密语列表非空**不会**让麦克风常驻密聊，需要按住密聊键才生效；列表里的文字消息仍会发给同一批目标
- 密语目标条目上限 10（服务器 `virtualserver_maxwhisperclients` 默认值），客户端 / 频道 / 用户组各算一个条目
- 本次原生库为 **arm64** 构建，仅支持 64 位 arm 设备（Android 8.0+）
