## 更新日志 (Changelog)

> 桌面端的「状态」菜单终于搬过来了：底栏左侧一个状态圆点，点开就是在线 / 离开 / 勿扰。

### 🟢 状态（在线 / 离开 / 勿扰）
- **底栏状态圆点**：绿 = 在线、琥珀 = 离开、红 = 勿扰，点开即桌面端那套状态菜单；长按自己那一行的面板里也有「修改状态」入口
- **在线**：`clientupdate client_away=0`，同时清掉离开消息
- **离开**：`client_away=1` + 离开消息，**麦克风照常可用**——TS3 的离开只是标记，不改变发声能力
- **勿扰**：同样是 `client_away=1`，但**麦克风被真正关掉**：按住说话、按住密聊、开放麦都开不了，采集链路上有一道独立闸门；切回在线（或切到离开）时恢复到当前模式应有的状态——按住说话保持静音，语音激活 / 开放麦重新开麦
- **自定义离开消息**：菜单内直接填（最多 100 字符），留空用默认文案（离开 / 请勿打扰）；随 `client_away_message` 发给服务器，别人长按你就能看到
- **断线重连后自动恢复**：重连会建一条新连接（服务器那边回到在线），客户端记住你选的状态并在重连成功后自动重新下发；只有主动断开才复位为在线
- **不会被服务器当成刷屏**：每次切换只发一条命令，连点由 600 ms 防抖合并，两条状态命令至少间隔 1.2 s；点已选中的状态不发命令，麦克风静音命令也只在真的变化时发。服务器的命令配额很小，超了会回 `client is flooding` 并把之后所有命令丢弃几十秒——这是「手机切了、别人一直看到在线」的真正原因；万一仍被限流，10 秒后自动补发一次

### 🐛 修复
- **悬浮窗里的密码框打不开键盘**：悬浮窗带 `FLAG_NOT_FOCUSABLE`（不抢前台焦点），这种窗口收不到输入法，密码框看得见却点不动。现在打开密码框时临时让窗口可聚焦并召唤键盘，关闭或切走时立刻恢复

### 👥 成员状态
- 成员列表里离开的人名字变暗并带月亮角标（一直如此），长按面板现在还多两行：**状态**与**离开消息**，能看出对方为什么不在

### 🔧 底层
- 原生库仍是 `tslib_multi` 8e0bc11，新增补丁 `patches/tslib_multi-8e0bc11-away-status.patch`（叠在 v2.1.7 的密聊补丁之上，`patch -p1` 可干净应用）
- `tslib-core` 新增 `set_away`（`clientupdate client_away` + `client_away_message` + 本地覆盖，与昵称同一套处理：服务端不回显 `clientupdate`），`tslib-jni` 新增 `nativeSetAway`
- 原生库按与 v2.1.7 相同的命令重新交叉编译（arm64-v8a，`--features vendored-openssl`）
- 单元测试 **75 → 79**（状态与离开消息的映射规则 + Rust 侧 4 项离开消息归一化：在线必清消息、空白等于没填）

### ⚠️ 注意
- 「勿扰」的静音是**本地**行为：其它客户端只能看到你的离开标记与离开消息
- 离开消息上限 100 字符（服务端允许更长，但成员列表里读不了那么多）
- 本次原生库仍为 **arm64** 构建，仅支持 64 位 arm 设备（Android 8.0+）
