## 更新日志 (Changelog)

> 新增桌面端同款「状态」菜单（在线 / 离开 / 勿扰），并修复状态不显示与悬浮窗密码框无法输入两个问题。

### 🟢 状态（在线 / 离开 / 勿扰）
- 底栏最左侧新增**状态圆点**（绿 = 在线、琥珀 = 离开、红 = 勿扰），点开即状态菜单；长按自己那一行的面板里也有「修改状态」入口
- **在线**：清除离开标记与离开消息
- **离开**：设置离开标记与离开消息，麦克风照常可用
- **勿扰**：在离开的基础上**关闭麦克风**，按住说话 / 按住密聊 / 开放麦都无法开麦；切回在线或离开时按当前麦克风模式恢复
- **自定义离开消息**：菜单内直接填写（最多 100 字符），留空使用默认文案（离开 / 请勿打扰）
- 掉线重连后自动恢复所选状态，主动断开才复位为在线

### 👥 成员状态
- 长按任意成员的面板新增「状态」与「离开消息」两行，成员列表里离开的人名字变暗并带月亮角标

### 🐛 修复
- **状态切换后其他客户端不显示**：状态切换只下发一条命令，连点会合并、命令之间保留最小间隔，不再触发服务器刷屏限制（`client is flooding`）而丢失命令；万一被限流，10 秒后自动补发一次
- **悬浮窗里带密码的频道无法输入密码**：打开密码框时临时允许窗口获取焦点并弹出键盘，关闭后立即恢复
- **麦克风静音状态**：只在状态真正变化时上报，避免无意义的重复命令

### 🔧 底层
- 原生库基于 `tslib_multi` 8e0bc11 加补丁自行交叉编译，新增补丁 `patches/tslib_multi-8e0bc11-away-status.patch`（叠加在 v2.1.7 的密聊补丁之上）
- `tslib-core` 新增 `set_away`，`tslib-jni` 新增 `nativeSetAway`（arm64-v8a，`--features vendored-openssl`）
- 单元测试 **75 → 79** 项

### ⚠️ 注意
- 「勿扰」的静音为本地行为，其他客户端只能看到离开标记与离开消息
- 离开消息上限 100 字符
- 本次原生库为 **arm64** 构建，仅支持 64 位 arm 设备（Android 8.0+）
